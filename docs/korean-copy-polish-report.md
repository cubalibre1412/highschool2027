## 대조·보존

숫자·연도·고유명사·조건·부정/긍정·확실성을 보존했습니다. 짧은 버튼·표제와 공식 규정·자료는 무리하게 고치지 않았습니다. 최초 P5 경고는 문장 분리로 인한 당위 정렬 경고였고, 해당 문장을 원문으로 복구했습니다. 불필요하게 추가한 ‘반드시’도 원문으로 복구했습니다.

## 남은 주의점

- 연결어미 뒤 쉼표 지표는 z +3.07에서 +1.30으로 부분 개선됐습니다. 최종 게이트에서는 경고 없이 통과했습니다.
- 이 결과는 UI 문구 목록의 언어적 윤문입니다. 입학·배정 규정의 사실 검증이나 프로그램 동작 검사는 아닙니다.
- 기능 수정과 동시에 진행되어, before가 현재 소스와 일치하는 34곳만 적용했습니다. 진학 차트 안내 1곳은 기능 수정에서 이미 바뀌어 이전 문구로 덮어쓰지 않았습니다. JSX 인라인 문구의 의미 있는 앞뒤 공백을 보존했습니다.
