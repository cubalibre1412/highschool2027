# 부천 고등학교 한눈에 · 2027

**v1.0.12** · 부천 일반고 22개교의 공개자료를 살펴보고, 관심 학교를 비교해 지망표를 정리하는 웹앱입니다.

운영: **배움의 온도 진수학 교습소** · [교습소 블로그](https://blog.naver.com/jinnmath)

## 주요 기능

- 학생 성별·중학교·관심 분야에 따른 학교 탐색
- 2026·2027학년도 모집정원과 2026학년도 실제 입학생 비교
- 관련 과목, 평가계획, 학업성취도, 졸업생 진학 현황 확인
- 최대 4개교의 과목과 주요 지표 비교
- 중학교 기준 직선거리·외부 길찾기·직접 확인한 통학시간 기록
- 지망 순서·메모 작성, JPG·PDF 바로 저장, 인쇄, CSV 및 JSON 백업
- 스마트폰·태블릿·PC 화면에 맞춘 반응형 구성

## 개발 환경

Node.js 22.14 이상, pnpm 11.25.0을 사용합니다. `pnpm-lock.yaml`으로 설치 버전을 고정합니다. API 키나 데이터베이스는 필요하지 않습니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

개발 화면: `http://localhost:3000`

## 빌드와 Cloud Run 실행

```sh
pnpm build
pnpm start
```

| 위치 | 용도 |
|---|---|
| `index.html` | React 앱의 빌드 시작 파일 |
| `src/` | 화면·기능 소스 |
| `public/` | 학교 데이터·원문 문서·PDF·로고 원본 |
| `dist/` | 빌드할 때 생성되는 배포 결과물 |
| `server.js` | 배포 결과를 제공하는 서버. `PORT` 환경변수 사용, 기본 8080 |
| `Dockerfile` | Cloud Run용 의존성 설치·빌드·서버 실행 설정 |

원본 자료는 `public`에서 관리합니다. Vite가 `dist`를 비우고 빌드해도 `public`의 자료를 다시 복사합니다. `dist`를 직접 수정하면 다음 빌드에서 변경이 사라집니다.

Google AI Studio·Cloud Run에서는 최신 코드를 가져와 다시 빌드·배포해야 합니다. GitHub 반영만으로 Cloud Run 배포가 완료되지는 않습니다. 최종 운영 주소는 별도로 확인하세요.

컨테이너를 직접 구성하는 경우:

```sh
docker build -t bucheon-school-guide .
docker run --rm -p 8080:8080 -e PORT=8080 bucheon-school-guide
```

[이전 Sites 배포본](https://bucheon-school-guide-2027.shannonham.chatgpt.site/)은 현재 React 수정본과 같다고 가정하지 마세요.

## PDF·차트 표시 기준

- **PDF 저장**은 한글과 여러 페이지를 담은 PDF 파일을 바로 내려받습니다. 인쇄는 별도 버튼입니다.
- PDF는 JPG와 같은 이미지 기반 페이지로 생성됩니다. 글자 선택·검색은 지원하지 않습니다.
- 통학시간 미입력은 `미입력`, 중학교 미선택 시 거리는 `중학교 미선택`, 미제공 수치는 `자료 없음`으로 표시합니다.
- 미입력·미제공 값을 0으로 바꾸지 않습니다. 확인된 실제 0은 `0명`, `0%`, `0점` 등으로 표시합니다.
- 졸업생 진학 차트는 국내 대학교·전문대학·국외 진학·취업·기타를 구분합니다.

## 자료 기준

| 항목 | 기준 |
|---|---|
| 2027 모집정원 | 교육청 신입생 전형계획 24쪽. 22개교 195학급, 총 4,836명 |
| 2026 모집정원 | 2025년 9월 8일 배포된 2026학년도 안내 자료 |
| 실제 입학생 | 학교알리미 2026년 공시 |
| 학업성취도·수강 과목 | 2026학년도 1학기, 2026년 9월 공시 |
| 국어·수학·영어 평가 비율 | 2026학년도 1학년 2학기 |
| 졸업생 진학 현황 | 2025년 공시 |

일부 교육과정 편제 요약은 2026학년도 입학생 자료입니다. 2027학년도 과목 선택·개설 여부와 최종 지원 일정은 학교·교육청의 최신 안내를 확인해야 합니다. 스캔 자료에서 추출한 본문에는 오탈자가 있을 수 있습니다.

수요 시나리오는 성별 `2026 실제 입학생 ÷ 2025 중3 학생 × 2026 중3 학생`을 기준으로 합니다. 지역 간 이동 등이 포함되므로 개인의 진학률·합격 가능성·배정 확률을 뜻하지 않습니다.

성취도 평균·과목 수·진학률만으로 학교의 우열이나 내신 유불리를 판단할 수 없습니다. 지망표는 검토용이며 공식 입학원서가 아닙니다.
