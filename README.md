# 부천 고교 선택 나침반 · 2027

**v1.0.6** · 부천 22개 일반고 지망을 준비하는 중학교 3학년 학생과 학부모를 위한 웹앱입니다.

[현재 앱 열기](https://bucheon-school-guide-2027.shannonham.chatgpt.site/)

## 포함 기능

- 학생 구분, 출발 중학교, 관심 항목에 따른 학교 탐색
- 중학교 기준 직선거리와 카카오맵 대중교통 길찾기, 직접 확인한 통학시간 기록
- 학교별 2026·2027 모집정원, 정원 증감, 2026 실제 입학생 비교
- 교육과정·실제 수업 과목, 국어·수학·영어 평가 비율과 과목별 성취도
- 2025 공시 졸업생 진학 현황과 남녀별 수요·정원 시나리오
- 최대 4개교 비교, 지망 순서·메모 기록, JPG·PDF 저장과 지원 기기에서 공유
- JSON 백업·복원, 보조 CSV 저장, 배정 일정·지원 안내·공식 자료 링크
- 스마트폰 가로·세로, 8~11인치 태블릿, PC 16:9 공간에 맞춘 반응형 화면

- 공식 전형계획에 따른 접수 확인사항, 예비소집, 문의처와 별도 신청 안내

- 관심 분야별 학교 수강 과목 탐색과 대학 학과 예시 제공

- 학교 찾기 설정에서 관심 분야 다중 선택·저장, 학교 목록의 관련 과목 요약
- 2~4개교 관심 분야별 과목 비교와 공통 과목 강조

- 배움의 온도 진수학 로고와 주황색·크림색 브랜드 디자인 적용

## 실행

별도 빌드, API 키, 데이터베이스 없이 실행되는 HTML·CSS·JavaScript 정적 앱입니다.

```sh
python -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 여세요. `index.html`을 파일로 직접 열면 자료를 불러오지 못할 수 있으므로 HTTP 서버를 사용하세요.

## Cloudflare Pages

GitHub의 이 저장소를 연결하고 아래 설정으로 배포할 수 있습니다.

| 항목 | 값 |
|---|---|
| 프로덕션 브랜치 | `main` |
| 프레임워크 | None |
| 빌드 명령 | 비워 둠 |
| 출력 디렉터리 | `dist` |
| 환경 변수 | 필요 없음 |

GitHub 반영과 Cloudflare 배포는 별도입니다. 이 저장소 등록만으로 Cloudflare 프로젝트가 생성되지는 않습니다.

## 파일 구성

- `dist/index.html`: 공통 화면 구조
- `dist/app.js`: 학교 탐색·비교·수요 계산·브라우저 저장
- `dist/ux.js`: 핵심 요약과 지망표 이미지·PDF 내보내기
- `dist/style.css`, `dist/ux.css`, `dist/responsive.css`: 스타일과 기기별 배치
- `dist/data.json`: 학교·중학교·정원·성취도·진학·요약·출처 데이터
- `dist/docs/`: 공시 문서 122개의 추출 본문
- `dist/*.pdf`, `dist/school-data.xlsx`: 배정·모집 관련 참고 파일
- `data/scan-recovery-index.json`: 재처리한 문서 8개와 문자 인식 페이지 목록

## 자료 기준

자료마다 공시 연도와 배포일이 다릅니다. 출처는 `dist/data.json`과 앱의 자료 안내에서 확인할 수 있습니다.

- 모집·배정 안내: 2027학년도. 학교별 모집정원은 2026년 10월 신입생 전형계획 24쪽 기준으로 22개교 195학급, 4,836명입니다. 기존 CSV 수치와 모두 일치합니다.
- 2026 모집정원: 2025.9.8. 배포된 2026학년도 안내 자료 기준입니다.
- 성취도: 2026학년도 1학기, 2026년 9월 공시.
- 평가 비율: 2026학년도 1학년 2학기 국어·수학·영어.
- 고등학교 졸업생 진학: 2025년 공시.
- 원미고·정명고 편제 요약: 2026학년도 입학생 편성표. 2027 입학생 확정 편제와 다를 수 있습니다.
- 중단됐던 문서 8개를 복구하고 이미지 38쪽을 한국어 OCR로 처리했습니다. 두 학교 편제 요약은 원본 이미지와 대조했으며 OCR 본문에는 오탈자가 있을 수 있습니다.

수요 시나리오는 성별 `2026 실제 입학생 ÷ 2025 중3 학생 × 2026 중3 학생`을 기준으로 합니다. 지역 간 이동 등이 포함되어 부천 중학생 개인의 진학률이나 학교별 합격·배정 확률을 뜻하지 않습니다.

학교의 성취도 평균·진학률만으로 내신 유불리나 학교 수준을 단정할 수 없습니다. 최종 지원은 최신 학교·교육청 안내로 확인하세요. 원문 저작권·이용조건은 각 출처에 따릅니다.

## 개인정보

이름·연락처·집 주소를 수집하지 않습니다. 선택 기준, 지망, 메모와 직접 입력한 시간은 현재 브라우저의 localStorage에 저장됩니다. 외부 길찾기 링크는 선택한 중학교·고등학교의 공개 좌표를 사용합니다. 분석·광고 추적 스크립트는 없습니다.
